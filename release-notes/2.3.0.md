## KoordASIO 2.3.0

The first stable release since 2.1.0. It brings three years of upstream FlexASIO
and PortAudio work into the driver, and replaces the control panel with a new one.

**[Download KoordASIO-Setup.exe](https://github.com/kormix-io/KoordASIO/releases/latest/download/KoordASIO-Setup.exe)** — 64-bit Windows, digitally signed.

### Driver

Merged with FlexASIO upstream (the 1.10b era) and moved onto a current PortAudio,
which is where most of the behavioural fixes come from:

- Sample rates are now checked against the device during exclusive-mode
  streaming, and validated through `Pa_IsFormatSupported`, so an unsupported rate
  is rejected up front instead of failing part-way into a stream.
- `GetLatencies()` now reports correctly for running streams, so hosts that ask
  the driver for its latency figures get real numbers.
- Stopping a stream no longer waits on `outputReady()`, removing a stall when a
  host stops the driver at the wrong moment.
- The config-file watcher was rewritten and debounced, so editing
  `.KoordASIO.toml` by hand no longer risks a partial read.
- PortAudio is linked correctly again, and the driver builds as C++20 against
  Visual Studio 2022.

### Control panel

Rewritten in Qt Quick. Same settings, less in the way:

- **Lives in the system tray.** Close the window and it keeps running; the tray
  icon reopens it and shows the current device, mode and buffer size on hover.
- **Only one instance** can run, so launching it again from an ASIO host brings
  the existing window forward instead of opening a second copy.
- **Present a mono device as stereo**, for hosts that insist on two channels.
- Every setting is written the moment you change it — there is no Save button.
- Tooltips throughout, and a link to the project page.

### Installing

- Installing over a running copy now works. The control panel stays resident in
  the tray, and the installer previously stopped rather than replace files it
  held open.
- The installer and both binaries are signed.
- The installer sets up a working configuration on first install: WASAPI
  Exclusive Mode, your Windows default recording and playback devices, and a
  32-sample buffer. Switch to Shared Mode in the control panel if you need other
  applications to use the same device at the same time.

### Notes

- KoordASIO is no longer distributed through the Microsoft Store. The installer
  above is the only supported download.
- If you are coming from 2.1.0, your existing `.KoordASIO.toml` is read as-is.
